# DeepSeen 选品参谋

作者：祥子｜跨境无疆&DeepSeen AI创始人

产品品牌：DeepSeen

面向TikTok跨境卖家，发现机会、验证商品。一个入口，两种起点：不知道卖什么就找方向，已有商品就直接验证。

## 独立安装

```sh
npx skills add kanehuang168/deepseen-product-advisor
```

只查看入口、不安装：`npx skills add kanehuang168/deepseen-product-advisor --list`。按需选择，不要求安装全部系列。宿主支持与费用按其实际能力为准。

- [deepseen-product-advisor-lite](skills/deepseen-product-advisor-lite/SKILL.md)

## 能交付什么

- 所给资料的机会初筛或商品验证单，明确事实、假设、反证和未知。
- 给下一环可直接使用的商品事实、目标受众、卖点与最小验证动作。
- [虚构杯子示例](skills/deepseen-product-advisor-lite/assets/cup-brief.md)，不包含真实销量、私人案例或供应商数据。

本地文字方法不需要DeepSeen账号；实时专业数据和云端任务是可选服务，连接后先查当前能力和报价。没有数据不输出确定市场结论，不保证收益或上架准入。
