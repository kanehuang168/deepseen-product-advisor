# 同一商品如何走完整条链

主要面向TikTok跨境卖家。每环可独立使用，不强制选品、创作和投放全部串行执行。

1. 选品参谋交付带来源和未知的商品交接单；已有商品直接验证，不重复探测。
2. 带货创作读取商品事实、用户确认稿和目标，交付分镜及验收要求。没有成片时仍为方案。
3. 用户自行拍摄，或在有效授权与实时预算下使用实际可用的制作服务，获得真正的成片文件。宿主没有制作能力时明确缺口。
4. 成品质检读取确认要求与最终文件；只对实际观察作结论。缺片、未听审或发现缺陷时保留待核验/返修，不把文件可播放当内容通过。
5. 用户实际投放后，投放诊断读取真实导出报表，区分广告归因成交、店铺总成交和自然流量，保留市场/币种/归因窗口。没有投放数据就停止于待数据，不自动建广告。
6. 复盘分别给素材/商品/报价/履约/数据口径的证据和假设。将确认的动作交回对应环节，不把每次失败都归因剧本，也不自动改变所有Skill。

示例的商品、报表和技术测试片必须标虚构/合成；它们验证交接与脚本，不能证明市场有效、真实生成成功或商业回报。
