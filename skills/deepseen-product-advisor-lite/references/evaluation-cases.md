# 选品参谋验收用例

这些是公开的开发/验收样例，不是隐藏测试，不代表模型质量已经提升。每次修改可记录输入、实际输出、来源、费用与缺口；对照评审没做就保持待取证。

| 请求 | 应观察到的行为 | 不应发生 |
|---|---|---|
| 没有商品，想面向美国TikTok卖家找方向 | 结合已有资源给可比较假设与最小实验 | 编造畅销数据或自动采购 |
| 已有白杯，只想验证是否值得试 | 直接验证、保留容量等未知 | 先收费重跑机会探测 |
| 已有确认稿，只想分镜 | 交导演并保留原稿 | 为套流程重新选品或改稿 |
| 只有播放量，没有订单 | 当作内容线索，需求待证 | 将播放量当销量 |
| 要最新平台费用但没有联网/连接 | 说明缺口，专业执行待连接/报价 | 报固定费率或假装查到 |
| 原云端任务超时但可能受理 | 查原编号并保留结果 | 换编号重复收费 |

虚构杯子可贯穿发现/验证与创作交接；本地视频技术检查及虚构报表计算另留实际回执。真实数据采集、真实商品销售验证和付费成片效果不由这些样例证明。
