# Optional cloud execution

This public method contains no credentials and creates no cloud jobs automatically. If live professional analysis is requested, discover the host's actual connector status, capability/schema and current quote. A tool in source code is not proof of live availability. Use the user's own connection or website login; never ask for keys in chat.

Existing products request validation only; an unknown direction may request opportunity discovery. Reuse valid paid evidence before buying again. State service, potential data charges, precharge and total ceiling; honor current scope/budget rather than historical approvals. Missing access, capability or budget pauses only that action; label any local supplied-material screening separately.

Before submission retain a stable request identifier and authorization summary. After acceptance retain authoritative job ID, outputs and remaining budget, not secrets or temporary signed URLs. Timeouts/unknown states require querying the original job, not another paid request. Billing/refunds follow real ledger evidence. Media production requires separate capability, price and applicable authorization. No procurement, posting or ad-budget changes are implicit.
